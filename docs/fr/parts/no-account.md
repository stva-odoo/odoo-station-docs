Android n'accepte un propriétaire de l'appareil que sur un appareil **sans aucun compte** : pas de compte Google, pas de compte Samsung ou Xiaomi, pas de profil professionnel, pas de second utilisateur.

1. Ouvrez **Paramètres › Comptes** (ou **Mots de passe et comptes**).
2. Supprimez tous les comptes. Ce qu'un compte n'a pas synchronisé est supprimé de l'appareil.

Vous pourrez remettre les comptes une fois la configuration terminée.
